# 아침 요약 중요도 기준

밤사이 들어온 AI 소식(출처와 제목)을 아래 기준에 따라 1등급·2등급·3등급으로 분류합니다.

## 등급 정의
- **1등급 (꼭 볼 것, 하루 3~5건)**: 아래 '기본 기준'의 높은 순위나 '이번 주 집중 주제'에 직접 해당하며, 오늘 바로 확인하거나 적용해 볼 가치가 큰 핵심 소식입니다.
- **2등급 (알아두면 좋은 것, 하루 5~10건)**: 당장 손대지 않더라도 흐름을 파악하거나 참고할 만한 유의미한 기술 글, 오픈소스, 논문, 업계 동향입니다.
- **3등급 (나머지)**: 일반론, 단순 감상, 가벼운 단신, 홍보성 툴 소개, 또는 이미 다룬 소식의 중복입니다.
- **중복 처리 원칙**: 같은 소식(동일 출시·논문·이슈)이 여러 출처(예: Hacker News와 GeekNews)에 함께 올라왔다면 가장 원문에 가깝거나 설명이 명확한 **하나만 높은 등급(1·2등급)**으로 올리고, 나머지는 3등급으로 내립니다.

---

## 1. 기본 기준

### 높은 순위 (1·2등급 우선 배정)
1. **지금 공부·개발과 바로 연결되는 것**: 멀티 에이전트 구조, 에이전트 오케스트레이션, Claude Code / Codex / Gemini CLI 활용법, Agent SDK, MCP(Model Context Protocol), 도구 호출(Tool Use) 설계와 실전 팁
2. **판을 바꾸는 소식**: 주요 AI 모델·신제품 출시, API 요금·무료 한도·할당량 변경, 주요 정책 및 약관 변경
3. **직접 따라 해볼 수 있는 것**: 구체적인 구현 튜토리얼, 바로 실행 가능한 오픈소스 예제 저장소, 실제 서비스 적용·디버깅 사례

### 낮은 순위 (3등급 배정)
- 구체적 기술 내용 없는 AI 산업 일반론·전망·칼럼
- 공식 발표 없이 기존 뉴스를 재가공한 2차 요약·재탕 글
- 단순 래퍼(Wrapper) 서비스나 유료 SaaS의 홍보성 툴 소개
- 제목만 자극적이고 실질적인 구현·코드·근거가 없는 글
